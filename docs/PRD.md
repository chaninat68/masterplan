## 3. โมดูลและฟีเจอร์

ป้าย: **[MVP]** ต้องมีก่อนเปิดใช้ · **[ต่อ]** ทำหลัง MVP

### M1 — Planning: Plan vs Actual (หัวใจของระบบ)
- [MVP] รายการโครงการ: ค้นหา/กรองตามสถานะ (Ongoing, On Hand, Hold, Completed, ยกเลิก), PM, Sales — แสดงสั่งซื้อ, ตอกแล้ว, คงเหลือ, %, Ahead/Behind, กำหนดเริ่ม-เสร็จ, วันคาดว่าเสร็จ
- [MVP] หน้าโครงการ: ข้อมูลโครงการ, KPI, กราฟ S-curve (แผนสะสม vs จริงสะสม + แท่งรายวัน), ประวัติรายวัน
- [MVP] **แก้แผนรายวัน** แบบตาราง (grid) เลือกช่วงวันที่ วางค่าจาก Excel ได้, ตัวช่วย "กระจายแผน" (เช่น 50 ต้น/วัน ตั้งแต่วันที่ X ถึง Y เว้นวันอาทิตย์)
- [MVP] **บันทึก Actual รายวัน** แทนแท็บ คิว-วัน: วันที่, โครงการ, ปั้นจั่น, ขนาดเสา, ความยาว, กะ A/B, จำนวนต้น — คำนวณ คิว/เมตร อัตโนมัติจากตาราง `pile_sizes`
- [MVP] Import .xlsx (รูปแบบคิว-วัน และ Master Planning) → แสดงตัวอย่าง (ใหม่/ซ้ำ/ผิด) → ยืนยัน → ย้อนกลับได้
- [MVP] **Export Master Planning** รูปแบบเดิม (คอลัมน์ A–Q + แถว Plan/Actual รายวัน) และ Export คิว-วัน
- [MVP] เพิ่ม/แก้โครงการ (จาก SO ที่อนุมัติ สร้างโครงการใหม่ได้ทันที)
- [ต่อ] ประวัติการแก้ไข (ใครแก้แผนอะไร เมื่อไร), อัพเดทหน้างาน/หมายเหตุ

### M2 — Manager Dashboard
- [MVP] KPI: ตอกเมื่อวาน / สัปดาห์นี้ / เดือนนี้ / ทั้งปี (เทียบช่วงก่อน), จำนวนโครงการ Ongoing, โครงการช้ากว่าแผน
- [MVP] รายการโครงการที่ช้าที่สุด (Behind) + ปุ่มดู S-curve
- [MVP] กราฟผลงานรายวัน/รายสัปดาห์/รายเดือน แยกปั้นจั่นเอเซีย vs ปั้นจั่นร่วม (แบบแท็บ คิว-สัปดาห์)
- [MVP] ผลงานตามบริษัทปั้นจั่น / หัวหน้าสาย / ประเภทโครงการ
- [MVP] ปุ่ม "คัดลอกสรุปส่ง LINE"
- [ต่อ] ค่าวัสดุสิ้นเปลืองต่อเดือน (กระสอบ, ลวดเชื่อม, จารบี, น้ำมัน, สลิง)

### M3 — Accounting (สรุปการเงิน)
- [MVP] มูลค่าผลงานต่อโครงการ: ตอกแล้ว × มูลค่าเฉลี่ย/ต้น, มูลค่างวดนี้ (ตามรอบวางบิลของโครงการ เช่น ทุก 7 วัน / เดือนละ 2 ครั้ง / ทุก 1 ผัง)
- [MVP] รายการ "ถึงรอบวางบิล" ในช่วงที่เลือก
- [MVP] ยอดขายสุทธิรายเดือน (P − R − C) จาก SO แยกเซลล์ / กลุ่มลูกค้า / ประเภทบริการ
- [MVP] Export .xlsx และ "คัดลอกไปวาง Excel"
- [ต่อ] ล็อกงวดเดือน (ตัวเลขงวดที่ปิดแล้วห้ามเปลี่ยน), ติดตามสถานะวางบิล/รับเงิน

### M4 — ภาพรวมบริษัท & Sales Alert
- [MVP] **Backlog**: งานคงเหลือรวม (ต้น และ บาท) แยก Ongoing / On Hand / Hold
- [MVP] **Runway** = Backlog ÷ อัตราตอกเฉลี่ย 4 สัปดาห์ → แสดงเป็นสัปดาห์ สีเขียว (≥ N+4) / เหลือง (N ถึง N+4) / แดง (< N) — N ตั้งค่าได้ในหน้า Admin (ค่าเริ่มต้น 8)
- [MVP] กราฟพยากรณ์: งานคงเหลือลดลงตามแผนรายสัปดาห์ เห็นว่าสัปดาห์ไหนงานจะหมด
- [MVP] Pipeline: SO รออนุมัติ (561 รายการ), โครงการ On Hand ที่ยังไม่เริ่ม
- [MVP] ยอดขายต่อเซลล์, ลูกค้าใหม่ vs เก่า, Top ลูกค้า
- [ต่อ] เป้ายอดขายรายเดือนต่อเซลล์, แจ้งเตือน LINE เมื่อ Runway เป็นสีแดง

### ~~M5 — ผู้ผลิต~~ — **ตัดออกจากขอบเขต** (23 ต.ค. 2569)
> ผู้ใช้สั่งยกเลิกส่วนผู้ผลิตออกก่อน (ฝ่ายผลิตนับเป็นท่อน ไม่ตรงกับหน่วยต้นของ SO / ตอก / ส่งมอบ) — ไม่มีหน้า /production และไม่มีบทบาท `production` ในระบบ

### M6 — ฝ่ายตอก (Drive Team)
- [MVP] คิวปั้นจั่น: วันนี้–7 วันข้างหน้า แต่ละปั้นจั่น/หัวหน้าสายไปโครงการไหน แผนกี่ต้น
- [MVP] ปั้นจั่นว่าง / โครงการที่แผนสูงแต่ยังไม่มีปั้นจั่น
- [MVP] Export Excel + ข้อความ LINE, ฝ่ายตอกล็อกอินดูเอง
- [ต่อ] หัวหน้าสายกรอก Actual จากมือถือ (ถ้า Q3 ตอบว่าให้กรอกเอง)

### Admin
- [MVP] ผู้ใช้ + บทบาท (เชิญด้วยอีเมล), ปิดการสมัครเอง
- [MVP] Master data: ขนาดเสา (หน้าตัด→ขนาด), ปั้นจั่น (ชื่อ ประเภท บริษัท), บริษัท + ชื่อเรียกอื่น, PM/Sales
- [MVP] ตั้งค่า: Runway N สัปดาห์, จำนวนวันที่ใช้คำนวณอัตราเฉลี่ย

## 4. User Stories

**Planning**
- ในฐานะ Planning ฉันต้องการบันทึกยอดตอกเมื่อวานจากรายงานทีม เพื่อให้ทุกคนเห็นตัวเลขล่าสุดทันที
- ในฐานะ Planning ฉันต้องการแก้แผนรายวันของโครงการเมื่อหน้างานเลื่อน เพื่อให้ Ahead/Behind ถูกต้อง
- ในฐานะ Planning ฉันต้องการ Export Master Planning รูปแบบเดิม เพื่อส่งคนที่ยังใช้ Excel ในช่วงเปลี่ยนผ่าน
- ในฐานะ Planning ฉันต้องการสร้างโครงการจาก SO ที่อนุมัติแล้ว เพื่อไม่ต้องพิมพ์ข้อมูลซ้ำ

**ผู้จัดการ**
- ในฐานะผู้จัดการ ฉันต้องการเห็นโครงการที่ช้ากว่าแผนมากที่สุดบนมือถือ เพื่อโทรตามได้ทันที
- ในฐานะผู้จัดการ ฉันต้องการเห็นว่างานในมือพอทำอีกกี่สัปดาห์ เพื่อสั่งเร่งทีมขายก่อนงานหมด
- ในฐานะผู้จัดการ ฉันต้องการเทียบผลงานปั้นจั่นเอเซียกับปั้นจั่นร่วม เพื่อวางแผนกำลังคน

**บัญชี**
- ในฐานะบัญชี ฉันต้องการรายการโครงการที่ถึงรอบวางบิลพร้อมมูลค่า เพื่อออกใบแจ้งหนี้ได้ตรงเวลา
- ในฐานะบัญชี ฉันต้องการยอดขายสุทธิรายเดือน (หักใบเปลี่ยนแปลง) เพื่อปิดงบ
- ในฐานะบัญชี ฉันต้องการ Export เป็น Excel เพื่อใช้ต่อในระบบบัญชี


**ฝ่ายตอก**
- ในฐานะฝ่ายตอก ฉันต้องการเห็นคิวปั้นจั่นของสัปดาห์ เพื่อย้ายเครื่องได้ทัน
- ในฐานะฝ่ายตอก ฉันต้องการรู้ว่าปั้นจั่นตัวไหนว่าง เพื่อรับงานเพิ่ม
- ในฐานะหัวหน้าสาย ฉันต้องการรู้เป้าวันนี้ของโครงการที่ไป เพื่อทำให้ทันแผน

## 8. ข้อเสนอแนะ
1. **เปลี่ยนผ่านแบบปลอดภัย**: ช่วงแรกให้เว็บ Export Master Planning ทุกวัน ถ้ามีปัญหายังกลับไปใช้ Excel ได้
2. **รหัสโครงการเป็น key กลาง**: บังคับรูปแบบ `A69-A101` ทุกจุดที่กรอก ป้องกันพิมพ์ผิด
3. **Master data ในเว็บ** แทน VLOOKUP ที่ error (ขนาดเสา, ปั้นจั่น, บริษัท, เซลล์) — แก้ที่เดียวถูกทุกหน้า
4. **เก็บแผนเป็นแถว** (โครงการ, วันที่, จำนวน) แทนแนวกว้าง ทำให้รายงานรายสัปดาห์/เดือนเร็วและไม่ต้องเพิ่มคอลัมน์ทุกวัน
5. **ต่อยอด**: แจ้งเตือน LINE เมื่อ Runway แดง หรือโครงการช้าเกิน X ต้น, รายงานสรุปสัปดาห์เป็น PDF ส่งอีเมล, ดึง SO อัตโนมัติจากระบบขาย
6. **เริ่ม MVP เล็ก**: Phase 1–3 (ข้อมูล + Planning) ใช้ได้จริงก่อน แล้วค่อยเปิดโมดูลอื่น
